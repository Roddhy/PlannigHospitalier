
# Projet de Planning Hospitalier — Application Java

Ce projet est une application Java réalisée dans un cadre académique, permettant de gérer le planning hospitalier : affectation de personnel, organisation des horaires.

---

##  Structure du projet à respecter

###  Nom du projet

* Créez un projet Java nommé `projet_hospitalier` (ou tout autre nom).

###  Arborescence des packages (dans `src/`) :

* `projet_hospitalier` → pour les **classes métiers** (respectez bien la casse)
* `dao` → pour les **classes d’accès aux données**
* `hospitaliertest` → pour les **tests unitaires**

###  Dossiers supplémentaires à créer :

* `resources/` → contient :

  * les **images** nécessaires (récupérées depuis ce dépôt Git)
  * les **fichiers CSS**
* `lib/` → pour les fichiers JAR :

  * Librairies **JDBC**
  * Librairies **JavaFX**
* `doc/` → contient la **documentation Javadoc** générée

---

##  Prérequis

* JDK 11 ou supérieur
* IDE Java (Eclipse, IntelliJ, etc.)
* JavaFX configuré
* Connecteur JDBC correspondant à votre base de données (MySQL, SQLite…)
